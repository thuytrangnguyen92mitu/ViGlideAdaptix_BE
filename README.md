## 📘 Project Overview

### Description
- **ViGlideAdaptix** is a modern web-based e-commerce platform focused on selling high-quality **shock absorbers** for vehicles. Built with usability and scalability in mind, the application allows users to easily browse, manage, and purchase products.

- The platform integrates **MoMo** and **VNPay** to support secure and convenient online payments.
